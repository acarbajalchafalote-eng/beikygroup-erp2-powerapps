# Instrucción para Codex Web (pegar en tarea sobre este repositorio)

Construye BEIKYGROUP ERP 2.0 como aplicación REAL Microsoft Power Apps Canvas. Lee AGENTS.md, README.md y todos los archivos de docs/ antes de editar. Parte del `base/ERP_BEIKYGROUP_ORIGINAL.msapp` y su código `fuente_original/Src/*.pa.yaml` (son de referencia), no de V11 fallida. La interfaz aprobada está en `referencia/Prototipo_UX_CRM_V10_NO_PRODUCTIVO.html`; no la uses como si tuviera persistencia. Aplica marca desde assets/ y manifest.json.

Primera meta: nueva app de desarrollo con portal de 7 módulos y CRM habilitado: clientes B2B por RUC; contactos; nueva oportunidad; listado (todos leen, solo dueños editan abiertas, administrador todas abiertas); consulta de SOLPED. Usa listas y flujos ya existentes; no crees tablas nuevas, ni modifiques flujos/producción. B2C pendiente.

Usa la cadena oficial Microsoft disponible en tu entorno. Instala .NET y Power Platform CLI si hace falta (dotnet tool install --global Microsoft.PowerApps.CLI.Tool); comprueba comando `pac canvas pack/unpack` y límites actuales, usa SourceCode y conserva copia sin tocar del original. Si puedes autenticarte de manera segura a Microsoft, crea app aparte y comprueba que Power Apps Studio la abra. No afirmes que un .msapp generado funciona si no probaste su importación. Si no puedes autenticarte, completa todo el código, tests y candidato en dist/ y reporta bloqueador exacto de publicación para que una sesión autorizada lo resuelva. No introduzcas secretos o claves. Entrega un PR/cambios y resultados de pruebas.
